# SnS Flowers & Events — GitHub Pages

This is a static HTML/CSS website prepared for GitHub Pages.

## Publish
1. Upload the contents of this folder to the **root** of a public GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Your site will be available at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Pages
- `index.html` — Home
- `products.html` — Products
- `events.html` — Events
- `gallery.html` — Gallery

## Notes about supplied images
The ZIP supplied for repair contained only these event-specific photos: `event.jpg`, `E1.jpg`, and `W1.jpg`. It did not contain the original wedding, birthday, other-event gallery photos or the two review photos referenced by the HTML.
To avoid broken-image icons, the missing gallery references have been redirected to the closest available supplied event image. Some gallery thumbnails will therefore repeat. The homepage also uses available images as substitutes for missing hero/best-seller/event photos. Replace these substitutes if you later recover the original images.

The image directory is named `images` (lowercase). Keep this capitalization when adding or referencing files; GitHub Pages paths are case-sensitive.

This is a static front-end demo. Any features requiring a server, database, form processing, or email backend will not work unless separately implemented.
